JCL Grading
Free open-source exam grading for convention or classroom use: build the answer sheet, write the key, print and scan, grade, and fix unclear marks.
How this works
Connect to the grading server. You only do this once per browser.

List the tests that go on it.
Enter the answer keys. This can wait until after the exam if you would rather.
Advanced settings, which most people can skip.
Scan the completed sheets and upload them here.
Fix anything unclear, and download the results.
Where data is stored: Your setup, answer keys, thresholds, and results are saved locally in this browser on this device. Uploaded scan PDFs are temporarily sent to the grading server for processing, then deleted; they are not retained on the server.

What goes in a cell
C
The answer is C.
ABD
The answer is A, B and D. The student must bubble all three.
A|BD
Either is accepted: A on its own, or B and D together.
X
Exclude this question from scoring. Use if you discover after the test that a question should not count.
-
You have not entered this answer yet (placeholder).
X means the question is finished and will not be scored, while - just means you have not typed it in yet.
Technical notes
Case does not matter. abd and ABD are the same answer, and so are x and X.
Order does not matter. BD and DB are the same answer.
More than two alternatives are fine. A|B|CD accepts A, or B, or C and D together. There is no limit on how many you list.
A repeated letter is an error. AA is rejected, as is a stray | such as A|, and any letter outside A–E.
Options A and B can be mixed. They write to the same answers, and the grid shows whatever is there.
Uploading merges, instead of replacing. A column whose Test ID matches a test you already have updates that test; anything else is added. Tests not mentioned in the file are left alone, and Undo upload puts everything back.
The file is Keys.csv. The first column has headers Name, Test ID, Excluded, then 1 to 80, with one further column per test.
Excluded may be written as Allowed instead, naming the levels that may sit each test rather than the ones that may not. Use one row or the other, not both. Excluded is left blank by default, which bars nobody and stays right when you add or rename a Latin level later.

5 Advanced Defaults
You don't need to change this for most runs.
Which tests to grade
Every test on the sheet is graded by default. An unticked test is not read at all: no results, no answer key needed, and nothing on the review sheets. Useful when a test is scored elsewhere, or when its key is not ready yet.
Which sides were scanned
Scanning one side only is for when a test is being re-marked on its own: the pages are then read one at a time instead of in front-and-back pairs, and a page of the other side is set aside rather than read. The front carries Test 1 and the back carries Tests 2 and 3, so a side you leave out takes its tests with it.
Skip blank pages
A duplex scanner produces an empty page for the back of a one-sided original, giving printed, blank, printed, blank. With this setting on, those empty pages are skipped. With it off, each one is reported as something that should not be there.
Marked-up scans
Mark-up scan
Marked-up scans show which bubbles were read as filled, along with the correct answer. They make a run noticeably slower, so leave this off unless you are demoing or debugging.

Thresholds
Every bubble is measured for darkness on a scale from 0 (blank paper) to 1 (solid black). A bubble darker than the cutoff counts as filled. One that lands between the review threshold and the cutoff goes to step 7 for a person to decide. Anything fainter is ignored.
Where those two cutoffs fall depends on the scanner, the paper, and how hard the students pressed. So the server measures them from each batch of scans rather than using fixed numbers.
Override thresholds (not recommended)
A higher number is stricter: it demands a darker mark. Leave a box empty to compute that one automatically — you can pin one number and let the other three be measured.
After a run, Calibration.txt shows the computed thresholds, so you can copy those numbers here to repeat it.

======================================================================
STEP 6 - Scan and grade
======================================================================
6 Scan and grade Nothing graded
At the scanner: required
Scan each sheet as two consecutive PDF pages: front first, back second. Do not scan all fronts first and all backs afterward. The run stops if the pages do not alternate, rather than grade the wrong back against the wrong front.
Turn off blank page removal. It will quietly drop a lightly-marked page, and a page dropped there is a page nobody knows is missing. Blank pages are counted and reported here instead.
Do not crop into the four corner marks. The reader finds the grid from them, so a tight auto-crop can make a page unreadable.
At the scanner: recommended
200–300 dpi. Color, grayscale or black and white all work; grayscale keeps the files small.
Deskew and auto-rotate can be left on or off. The reader straightens the page itself and corrects one that comes through sideways or upside down, so neither setting will break a batch.
Save one PDF per batch of about 25 sheets — your scanner can usually start a new file every 50 pages for you. This keeps each upload small enough for the server to handle; the hard limit is 40 MB. If a scan is too big, break it into smaller pieces and add each as its own batch.
Grading
A batch is one PDF from the scanner, holding whole sheets. Each is graded on its own and keeps its own results, so you can start grading the first stack while the rest is still being scanned.
If a mark was read wrong or the key was wrong, fix it in step 7: that re-scores from the results already here, without re-reading the scans. If the paper itself needs re-reading, scan it again and add it as a new batch — a batch that has been graded stays as it was.

======================================================================
STEP 7 - Fix unclear marks
======================================================================
7 Fix unclear marks Nothing to review
An unclear bubble is too faint to be definitively filled. A missing bubble is a required field it could not read at all. A question left blank is not an error: that is the student's choice.
Each file asks for one correction per row. Open it, check the paper, fill in the answer, mark the row Done, and upload it below. The Done column should read TRUE. A row you have not ticked is left exactly as it was and comes back as a shorter file to finish next time, so you can do half now and half later.
Correcting something that was never flagged
You can add rows too. A student whose answer was read confidently wrong never reaches these files, and a row you write by hand is how to fix it.
A row needs enough of File, Page, Test, Test ID and Student ID to pick out exactly one test. The Student ID and the Test ID normally do it. Then the question number and the answer:
