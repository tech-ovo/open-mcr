JCL Grading

Free open-source exam grading for convention or classroom use: build the answer sheet, write the key, print and scan, grade, and fix unclear marks. Your work is kept in this browser only. Scans are sent to the grading server, processed, returned, and discarded.

Printing

Print double-sided, flipping on the long edge, at 100% scale. "Fit to page" also reads correctly, but it shrinks the bubbles for no benefit. Do not print two pages to a sheet.

4 Enter the answers No answers yet

The answers end up in one file, Keys.csv: a row for each of the 80 questions, a column for each test. It is sent with every batch you grade, and you never have to touch it by hand unless you want to. There are three ways to fill it in, and you can mix them — they all write to the same grid at the bottom of this step.

Either: fill it in a spreadsheet

Download the template, type the answers into the numbered rows in Excel or Google Sheets, then bring the file back. Uploading does not throw away the tests you already have: a column whose Test ID matches is updated, and anything else is added.

Or: paste them in

One box per test. Separate the answers with spaces, commas or newlines, or paste one unbroken string like ABCDE….

Or: type them into the grid

Every answer is editable here, whichever way it got in. An edited cell is shown in bold.

What goes in a cell

  • One letter for the usual case: C.
  • Several letters mean all of them are required: ABD is only right if the student marked A, B and D.
  • A | separates alternatives, and each alternative may be several letters: A|BD accepts A on its own, or B and D together.
  • X leaves the question unscored — use it to retire a question after the fact. It counts against nobody and appears in no score.
  • A - marks a question you have not filled in yet. It is how a gap keeps its place, so that question 41 stays question 41.
5 Thresholds Automatic

The server automatically determines a cutoff for deciding whether a bubble counts. It measures it from each batch of scans, so a different scanner needs no adjustment.

Every number measures darkness, from 0 (blank paper) to 1 (solid black). A bubble above the cutoff counts as filled, and one between the review threshold and cutoff is sent for review. Leave a box empty to compute it automatically.

After a run, Calibration.txt shows the computed thresholds, so you can copy those numbers here to repeat it.

6 Scan and grade Nothing graded

At the scanner

  • Scan double-sided, front page first, so every sheet is two consecutive pages.
  • 200–300 dpi. Color, grayscale or black and white all work.
  • Turn off auto-rotate, deskew, auto-crop and blank page removal. Blank page removal will quietly drop a lightly-marked page and throw the whole batch out of order.
  • Save one PDF per batch of about 25 sheets. Your scanner can usually do this for you — set it to start a new file every 50 pages.

Grading

One batch per PDF. Each is graded on its own and keeps its own results, so you can start grading the first stack while the rest is still being scanned. A batch cannot be re-graded once it is done — add a new one.

Marked-up scans show which bubbles were marked as filled, along with the correct answer. They make a run noticeably slower, so turn off unless you are demoing or debugging.

7 Fix unclear marks Nothing to review

Two kinds of thing reach this step. Unclear is a bubble too faint to call — the reader neither counts it nor ignores it, and asks instead. Missing is a required field it could not read at all. A question left blank is not an error: that is the student's choice.

Each file asks for one correction per row. Open it, look at the marked-up scan or the paper, fill in the answer, tick Done, save, and bring it back here.

Google Sheets is optional

Any editor that saves CSV will do — Excel, Numbers, even a text editor. Google Sheets is worth the setup if more than one person is correcting, or if you would rather have checkboxes than type TRUE: the script below adds them, restores leading zeros on the Student IDs, fits the columns and trims the blank rows.

  1. Make a Google Sheet you will reuse for the whole event.
  2. Extensions → Apps Script, paste in review_sheet.gs, and Save.
  3. Click the Triggers (clock) icon → Add Trigger: function onSpreadsheetChange, source From spreadsheet, type On change. Save and accept the prompt.
  4. For each file: File → Import → Insert new sheet(s). It has to create a new sheet — "Replace current sheet" will not trigger the script.
  5. When the sheet is finished, File → Download → Comma-separated values.

However you edit it, every row needs Done ticked. An untouched row will be refused, because it means nobody has looked at it.

Nothing you upload is kept on the server. Each batch is unpacked into a temporary folder, graded, and deleted before the results come back — there is no database and no file store behind this page. Your tests, answers, thresholds and results are held in this browser, on this device, so you can close the page and come back to it. Scans are never stored on either side.
